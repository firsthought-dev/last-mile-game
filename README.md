## 🎮 Playable Games

### 🚚 Last Mile: Shiplyp Chronicles (`/last-mile-game`)
An authentic top-down arcade last-mile delivery game celebrating Indian street logistics across four distinct tracks:
- **Track 1: Morning Newspaper Boy (4:00 AM – 6:00 AM)**: Dawn lighting transitions, bicycle physics, precision parabolic newspaper toss, street dog AI chases, potholes & speed breakers.
- **Track 2: Doodhwala (Milk Delivery)**: Sloshing milk canister balance physics & interactive doorstep measurement pitcher mini-game.
- **Track 3: Shiplyp Express Courier**: Fast scooter dashes, lane splitting, and customer OTP SMS verification.
- **Endless Challenge**: Dynamic procedural deliveries across the entire colony.
- **Economy & Upgrades**: ₹ INR currency earnings, garage shop (MRF tires, cargo baskets, dynamo LED light, Parle-G dog treats).
- **Procedural Web Audio**: Synthesized bicycle bell *trin-trin*, scooter horn *pom-pom*, dog barks, coin pickup, and ambient dawn soundscapes.

#### How to Run Locally:
Open `last-mile-game/index.html` in any modern web browser or serve statically:
```bash
npx serve last-mile-game
# or
python3 -m http.server 8080 --directory last-mile-game
```
