## Strategic Objective
Productize the AI-assisted game development and monetization methodology demonstrated by Anul Agarwal (Momo Games) and build out a multiplatform distribution machine for Shiplyp (Last-Mile Game) and future procedural AI titles.

## Strategic Pillars

### 1. Multiplatform Publishing Machine for Shiplyp
- [x] **Web & Mobile Cross-Platform Architecture**: WebGL + Three.js + Touch/Drag controls + Android Studio WebView wrapper.
- [x] **Career & Progression Economy**: Shift payouts, vehicle unlocking modal, fleet gating.
- [ ] **Web Game Portals Distribution**:
  - Integration with **GameDistribution HTML5 SDK** (Pre-roll & Interstitials).
  - Integration with **CrazyGames SDK** (Rewarded 2x earnings multiplier).
  - Clean HTML5 single-zip portal packaging script.
- [ ] **Mobile App Store Launch**:
  - Google Play AAB release signing (`targetSdk 35`).
  - Google Play Store listing assets, screenshots, privacy policy.
  - Rewarded Ad & In-App Purchase integration via Android JavascriptInterface.

### 2. Standalone AI Game Making Tool Productization
- [ ] **Prompt Orchestration Engine**: Prompt $\to$ Structured Game JSON schema (Mechanics, Entities, Controls, Win/Loss Conditions).
- [ ] **Engine Target Runtime**: Phaser.js / Three.js template scaffolding.
- [ ] **Automated Asset Pipelines**:
  - 2D Sprite extraction & palette harmonization via `sprite-gen`.
  - Web Audio procedural SFX synthesis scripts.
- [ ] **One-Click Publishing Pipeline**: Auto-injected Ad SDKs and downloadable web bundle.
