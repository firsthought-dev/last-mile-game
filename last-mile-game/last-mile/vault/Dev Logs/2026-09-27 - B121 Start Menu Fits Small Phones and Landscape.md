# 2026-09-27 — B121 Start Menu Fits Small Phones and Landscape
- **Fixed:** on small phones (iPhone SE, Galaxy A-series) the start menu was cut off at the bottom, and the FIRST DELIVERY / DRIVE button was hidden or half visible. The menu now fits the visible screen, including the space the browser toolbar takes.
- **Fixed:** with the phone held sideways, the start menu was clipped at the top and bottom and the start button couldn't be reached. The menu now scrolls, and the start button is always visible.
