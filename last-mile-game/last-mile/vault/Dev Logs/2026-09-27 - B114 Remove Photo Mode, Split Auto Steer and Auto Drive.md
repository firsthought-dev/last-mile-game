# 2026-09-27 — B114 Remove Photo Mode; Split Auto Steer / Auto Drive
- Photo/postcard mode has been removed.
- The single AUTO control is now two assists; turning one on turns the other off:
  - **Auto Steer** (F, A-STEER): the original autopilot. It steers and controls speed.
  - **Auto Drive** (G, A-DRIVE): speed only. It speeds up on straights and eases off before bends; you steer.
- Braking turns off either one.

**Status:** merged to main via PR #10. On-device Android check pending.
