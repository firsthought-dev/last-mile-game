# B200–B206: Unused code and asset cleanup

**Date:** 2026-10-24

Removed unused legacy code and an unused texture, and switched the style previews to a lighter image format. The download is smaller and nothing changes for players.

- Old code that the game no longer ran was taken out, so the build is leaner and easier to maintain.
- One unused road texture was removed from every build.
- The two animated style previews on the start screen now use a lighter image format and look the same.
- Hidden developer-only camera shortcuts were removed.

Checked after every step: the game builds, starts and drives on desktop and phone sizes, the automatic world checks give the same results as before, and each vehicle still drives.
